# k6 — Guía de Referencia

> Herramienta de load testing basada en JavaScript de Grafana. Ideal para: escenarios complejos, stages/ramping, thresholds nativos, reportes HTML nativos y web dashboard.

## Instalación

```bash
# macOS
brew install k6

# Docker
docker run --rm -i grafana/k6 run - <script.js
```

## Script Básico

```javascript
import http from 'k6/http';
import { check, sleep } from 'k6';

export const options = {
  vus: 50,
  duration: '30s',
  thresholds: {
    http_req_duration: ['p(95)<3000'],  // 95% of requests < 3s
    http_req_failed: ['rate<0.01'],      // <1% errors
  },
};

export default function () {
  const payload = JSON.stringify({
    event_id: 237769,
    app_name: 'insiders',
    body_req: [{
      ticket_type_id: 394839,
      quantity: 1,
    }],
  });

  const params = {
    headers: {
      'Content-Type': 'application/json',
      'application-name': 'insiders',
    },
  };

  const res = http.post(
    'https://web-api-qa.example.com/bookings-core/api/v1/bookings/generate-booking',
    payload,
    params
  );

  check(res, {
    'status is 200': (r) => r.status === 200,
    'latency < 1s': (r) => r.timings.duration < 1000,
  });

  sleep(0.1);
}
```

## Ejecución

```bash
# Ejecución básica
k6 run script.js

# Con web dashboard (gráficas en tiempo real en localhost:5665)
k6 run --out web-dashboard script.js

# Salida JSON para análisis personalizado
k6 run --out json=results.json script.js

# Salida CSV
k6 run --out csv=results.csv script.js

# VUs y duración específicos (sobreescribe las opciones del script)
k6 run --vus 100 --duration 1m script.js
```

```javascript

  thresholds: {
    http_req_duration: ['p(95)<3000'],
  },
```

## Checks y Thresholds

```javascript
export const options = {
  thresholds: {
    http_req_duration: ['p(50)<1000', 'p(95)<3000', 'p(99)<5000'],
    http_req_failed: ['rate<0.005'],   // <0.5% errors
    checks: ['rate>0.99'],             // >99% checks pass
  },
};
```

k6 sale con código 99 si se superan los thresholds — útil para gates de CI/CD.

## Gráficas Personalizadas desde Salida JSON

```python
import json
import matplotlib.pyplot as plt
from collections import defaultdict

# Parse k6 JSON output
completions = defaultdict(int)
latencies = defaultdict(list)

with open('results.json') as f:
    for line in f:
        point = json.loads(line)
        if point['type'] == 'Point' and point['metric'] == 'http_req_duration':
            ts = int(point['data']['time'][:19].replace('T', ' '))  # simplify
            latencies[ts].append(point['data']['value'])
            completions[ts] += 1

# Chart completions per second
seconds = sorted(completions.keys())
fig, ax = plt.subplots(figsize=(14, 6))
ax.bar(range(len(seconds)), [completions[s] for s in seconds], color='#3498db')
ax.set_xlabel('Second')
ax.set_ylabel('Requests completed')
plt.savefig('chart-k6-completions.png', dpi=150)
```
