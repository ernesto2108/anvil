# Handoff Template

---

- [ ] Step 2: description
- [ ] Step 3: description

<!-- path — what was done and why -->

## Decisiones tomadas
<!-- decision — reasoning -->

<!-- Exactly what to do next to resume work -->

## Notas
<!-- Non-obvious context: workarounds, bugs found, blockers -->
