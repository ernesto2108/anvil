# k6 — Reference Guide

> JavaScript-based load testing by Grafana. Best for: complex scenarios, stages/ramping, built-in thresholds, native HTML reports and web dashboard.

## Install

```bash
# macOS
brew install k6

# Docker
docker run --rm -i grafana/k6 run - <script.js
```

## Basic Script

```javascript
import http from 'k6/http';
import { check, sleep } from 'k6';

export const options = {
  vus: 50,
  duration: '30s',
  thresholds: {
    http_req_duration: ['p(95)<3000'],  // 95% of requests < 3s
    http_req_failed: ['rate<0.01'],      // <1% errors
  },
};

export default function () {
  const payload = JSON.stringify({
    event_id: 237769,
    app_name: 'insiders',
    body_req: [{
      ticket_type_id: 394839,
      quantity: 1,
    }],
  });

  const params = {
    headers: {
      'Content-Type': 'application/json',
      'application-name': 'insiders',
    },
  };

  const res = http.post(
    'https://web-api-qa.example.com/bookings-core/api/v1/bookings/generate-booking',
    payload,
    params
  );

  check(res, {
    'status is 200': (r) => r.status === 200,
    'latency < 1s': (r) => r.timings.duration < 1000,
  });

  sleep(0.1);
}
```

## Execution

```bash
# Basic run
k6 run script.js

# With web dashboard (real-time charts at localhost:5665)
k6 run --out web-dashboard script.js

# JSON output for custom analysis
k6 run --out json=results.json script.js

# CSV output
k6 run --out csv=results.csv script.js

# Specific VUs and duration (override script options)
k6 run --vus 100 --duration 1m script.js
```

## Native Reports

### Web Dashboard (real-time)
```bash
k6 run --out web-dashboard script.js
# Opens http://localhost:5665 with live charts
```

### HTML Report (post-test)
Install the reporter extension:
```bash
# In your script, add:
import { htmlReport } from "https://raw.githubusercontent.com/benc-uk/k6-reporter/main/dist/bundle.js";

export function handleSummary(data) {
  return {
    "report.html": htmlReport(data),
    stdout: textSummary(data, { indent: " ", enableColors: true }),
  };
}
```

### JSON Summary
```bash
k6 run --summary-export=summary.json script.js
```

## Stages (ramping)

```javascript
export const options = {
  stages: [
    { duration: '10s', target: 10 },   // ramp up to 10 users
    { duration: '30s', target: 50 },   // ramp to 50
    { duration: '1m', target: 50 },    // sustain 50
    { duration: '10s', target: 0 },    // ramp down
  ],
  thresholds: {
    http_req_duration: ['p(95)<3000'],
  },
};
```

## Constant Request Rate (like Vegeta)

```javascript
import { constantRate } from 'k6/execution';

export const options = {
  scenarios: {
    constant_load: {
      executor: 'constant-arrival-rate',
      rate: 50,              // 50 req/s
      timeUnit: '1s',
      duration: '30s',
      preAllocatedVUs: 100,  // pool of VUs
      maxVUs: 200,
    },
  },
};
```

## Checks and Thresholds

```javascript
export const options = {
  thresholds: {
    http_req_duration: ['p(50)<1000', 'p(95)<3000', 'p(99)<5000'],
    http_req_failed: ['rate<0.005'],   // <0.5% errors
    checks: ['rate>0.99'],             // >99% checks pass
  },
};
```

k6 exits with code 99 if thresholds are breached — useful for CI/CD gates.

## Custom Charts from JSON Output

```python
import json
import matplotlib.pyplot as plt
from collections import defaultdict

# Parse k6 JSON output
completions = defaultdict(int)
latencies = defaultdict(list)

with open('results.json') as f:
    for line in f:
        point = json.loads(line)
        if point['type'] == 'Point' and point['metric'] == 'http_req_duration':
            ts = int(point['data']['time'][:19].replace('T', ' '))  # simplify
            latencies[ts].append(point['data']['value'])
            completions[ts] += 1

# Chart completions per second
seconds = sorted(completions.keys())
fig, ax = plt.subplots(figsize=(14, 6))
ax.bar(range(len(seconds)), [completions[s] for s in seconds], color='#3498db')
ax.set_xlabel('Second')
ax.set_ylabel('Requests completed')
plt.savefig('chart-k6-completions.png', dpi=150)
```
